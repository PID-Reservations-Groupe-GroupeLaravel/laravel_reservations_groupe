PHASE 1: CONFIGURATION (15 min)
─────────────────────────────────────────────────────────────────────────────
☐ 1. S'inscrire DeepL (https://www.deepl.com)
     └─ Free tier: https://www.deepl.com/account/keys
     └─ Copier la clé API

☐ 2. Configurer Google Cloud (https://console.cloud.google.com)
     └─ Créer un projet
     └─ Activer l'API: "Cloud Translation API"
     └─ Créer une clé de service (JSON)

☐ 3. Installer Redis
     ├─ Linux: sudo apt-get install redis-server
     ├─ macOS: brew install redis
     └─ Windows: WSL2 + apt-get install redis-server

☐ 4. Ajouter au .env:
     DEEPL_ENABLED=true
     DEEPL_API_KEY=votre_clé
     GOOGLE_TRANSLATION_ENABLED=true
     GOOGLE_TRANSLATION_API_KEY=votre_clé
     TRANSLATION_CACHE_DRIVER=redis
     REDIS_DB=1

PHASE 5: TESTS (10 min)
─────────────────────────────────────────────────────────────────────────────

Test 1: Détecter la langue

> $service->detectLanguage("Bonjour le monde")

Test 2: Traduire vers l'anglais
─────────────────────────────────
> $service->translateTo("Bonjour", "en")
=> "Hello"

Test 3: Traduire vers toutes les langues
──────────────────────────────────────────
