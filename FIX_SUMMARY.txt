PROBLEM IDENTIFIED:
───────────────────────────────────────────────────────────────────────────────
"La tradition n'a pas d'effet sur les reviews ou sur les commentaires"
(Translation has no effect on reviews or comments)

ROOT CAUSE:
───────────────────────────────────────────────────────────────────────────────
The review creation endpoint (POST /shows/{id}/reviews) was NOT calling the
TranslationService at all. The database columns existed, the migration existed,
the Review model was updated, BUT the actual API route was NOT using them.
